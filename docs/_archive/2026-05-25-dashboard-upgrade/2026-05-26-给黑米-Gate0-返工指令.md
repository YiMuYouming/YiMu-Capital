## 阻断 2：三个采集器默认路径嵌套多了一层 live-dashboard/

**现象：** iwencai_poll.py (line 12)、market_data.py (line 12)、poll_iwencai.py (line 20) 的 `default` 计算结果为：
`/Users/yimu/Documents/YM_Capital/live-dashboard/live-dashboard/YM-data-pipeline`（多了一层 live-dashboard/）。

**根因：** `Path(__file__).resolve().parent.parent.parent` 三层 parent 对这三个在 `scripts/collectors/` 或 `scripts/` 的文件来说层级算多了。

**当前错误计算：**
- `scripts/collectors/iwencai_poll.py`：`__file__` = `scripts/collectors/iwencai_poll.py`
  - `.parent` = `scripts/collectors`
  - `.parent.parent` = `scripts`
  - `.parent.parent.parent` = `live-dashboard` ← 这是正确的顶层
  - 再 `.parent` = `YM_Capital`（错误！）

实际：
- `scripts/collectors/*.py`：`__file__` → parent = `scripts/collectors` → parent = `scripts` → parent = `live-dashboard`（只需 2 层 parent）
- `scripts/*.py`（poll_iwencai.py）：`__file__` → parent = `scripts` → parent = `live-dashboard`（只需 1 层 parent）

**修复要求：**
- `scripts/collectors/iwencai_poll.py` line 12：改为 `.parent.parent / "YM-data-pipeline"`（2 层 parent）
- `scripts/collectors/market_data.py` line 12：改为 `.parent.parent / "YM-data-pipeline"`（2 层 parent）
- `scripts/poll_iwencai.py` line 20：改为 `.parent / "YM-data-pipeline"`（1 层 parent）
- quotes.py 已正确使用 3 层 parent（文件在 `scripts/collectors/` 下），保持不动。

**验收命令：**
