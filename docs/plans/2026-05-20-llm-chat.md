# AI盯盘交互升级 实施计划 (v2)

**目标：** W20 从单向研判升级为浮动对话框 + 15min主动通知 + 用户交互问答

**架构：** 快照统一后端 `_build_full_snapshot()` → 前端只传 `{node, mode, question}` → bridge /api/llm 调用 DeepSeek → 结构化输出 → 持久化 llm_insights.json（新 conversation 格式）+ Toast通知。llm-chat 继承 `YiMuWidget` 管理生命周期。W20 网格保留摘要视图，定时逻辑统一在 llm-chat。

**技术栈：** 纯 HTML/CSS/JS + Python bridge + DeepSeek-V4-Flash + JSON 持久化。pnl.db llm_insights 表结构不变。

**用户决策：**
- 聊天记录跨会话保留 · 通知：Toast+按钮红点 · W20 网格保留摘要+浮动框做对话
- 研判扫全部数据 · 模型保持 DeepSeek-V4-Flash

---

## 架构决策（评审确认）

| # | 决策 | 理由 |
|---|------|------|
| 1 | **快照数据源统一后端** `_build_full_snapshot()` | 前端 `_buildSnapshot()` 废弃，避免双路径维护 |
| 2 | **llm-chat.js 继承 YiMuWidget** | 统一生命周期管理，定时器走 `_startTimers()` |
| 3 | **pnl.db 不变** | `llm_insights` 表保持单行一条研判，conversation JSON 仅用于前端展示 |
| 4 | **W20 定时逻辑删除不保留** | llm-monitor 的 `_startTimers` 直接删，不留过渡期，避免双重定时 |
| 5 | **红点用 focus/blur 控制** | 不在 panel 显隐上判断——面板内聚焦时清红点，失焦时恢复未读计数 |

### 任务 1: bridge `/api/llm` 增强 — 对话模式 + 快照统一

**文件：**
- 修改: `scripts/bridge.py` — `/api/llm` handler 重写

**接口变更：**

| 字段 | 类型 | 自动模式 | 手动模式 | 说明 |
|------|------|---------|---------|------|
| `mode` | string | `"auto"` | `"manual"` | 触发类型 |
| `node` | string | 后端取当前时间 | 后端取当前时间 | 服务端生成，不再信任前端 |
| `question` | string | — | 必填 | 用户提问文本 |

**Prompt 模板：**
- 自动：`"当前时间: {node}\n\n全盘数据:\n{full_snapshot}"`
- 手动：`"用户提问时间: {node}\n用户问题: {question}\n\n全盘数据:\n{full_snapshot}\n\n请针对用户问题给出研判。回答要具体，引用实时数据。"`

**Rate Limit（手动模式）：**
- 服务端：同一 session 每分钟最多 10 次 → 超限返回 `{"ok":false, "error_type":"rate_limit", "error":"请求太频繁，请30秒后再试"}`。用内存 dict `{session_id: [(ts, ...)]}` 实现，不持久化。
- 前端：发送按钮 loading 态 + 30s cooldown

**Context Window 管理：**
- snapshot 精简：只传关键字段（涨跌幅只传 % 不传价格注释等冗余信息）
- conversation history 只带最近 3 轮（user+assistant 各 3 条），不作为 prompt 的一部分，仅用于 `/api/llm/history` 返回

**错误码细化：**

| error_type | HTTP | 含义 |
|-----------|------|------|
| `auth` | 502 | API token 未配置 |
| `timeout` | 504 | LLM 超时 |
| `rate_limit` | 429 | 手动模式调用过频 |
| `parse_error` | 500 | LLM 返回格式异常 |

**提交：** `feat: /api/llm 对话模式+快照后端统一+限流+错误码`

**旧格式自动转换：**
```python
def _migrate_to_v2(day_data):
    if 'conversation' in day_data:
        return day_data  # 已是 v2
    conv = []
    for node, entry in sorted(day_data.items()):
        if isinstance(entry, dict) and 'text' in entry:
            conv.append({'role':'assistant', 'ts':entry.get('timestamp',''), 'text':entry['text'], 'signals':entry.get('signals',[]), 'auto':True})
    return {'meta': {}, 'conversation': conv}
```

**类结构（继承 YiMuWidget，复用基类生命周期 + this._timers 自动清理）：**
```javascript
class LlmChatWidget extends YiMuWidget {
  constructor(config) {
    super(config);
    this._conversation = [];
    this._loading = false;
    this._badgeCount = 0;
    this._cooldown = false;
    this._lastTriggerTime = 0;
  }

  // === 生命周期 ===
  mount(container) {
    // 调用基类 mount 会走 _renderShell → _renderBody → _subscribe → _startTimers
    // 但聊天框不走 GridStack，手动接管
    this._container = container;
    this._initDOM();           // 构建聊天框 HTML
    this._bindEvents();        // 关闭/发送/回车/聚焦
    this._loadHistory();       // GET /api/llm/history → _conversation
    this._startTimers();       // 启动 15min 自动研判定时器
  }
  unmount() {
    super.unmount();  // 基类清理 _timers + _domListeners
    this._conversation = [];
  }

  // === 定时器（push 进 this._timers，基类 unmount 自动 clearInterval）===
  _startTimers() {
    var self = this;
    var timer = setInterval(function() {
      if (self._shouldTrigger()) self._triggerAuto();
    }, 30000);
    this._timers.push(timer);
  }

  // === 核心逻辑 ===
  _shouldTrigger() {
    var now = new Date();
    var mins = now.getHours() * 60 + now.getMinutes();
    if (mins < 565 || mins > 905) return false;  // 非盘中 (9:25-15:05)
    if (Date.now() - this._lastTriggerTime < 840000) return false;
    return true;
  }
  _triggerAuto() {
    this._lastTriggerTime = Date.now();
    this._send('', 'auto');
  }
  _sendManual(question) {
    if (this._cooldown) return;
    this._cooldown = true;
    setTimeout(function() { this._cooldown = false; }.bind(this), 30000);
    this._send(question, 'manual');
  }
  _send(question, mode) {
    // 手动模式先追加 user 气泡
    if (question) {
      this._conversation.push({role:'user', ts:this._now(), text:question, signals:[], auto:false});
      this._renderMessages();
    }
    this._loading = true;
    this._renderMessages();  // 显示 typing 指示器
    fetch('/api/llm', {
      method:'POST',
      headers:{'Content-Type':'application/json'},
      body: JSON.stringify({mode:mode, question:question||''})
    })
    .then(function(r) { return r.json(); })
    .then(function(res) {
      this._loading = false;
      if (res.ok) {
        this._conversation.push({
          role:'assistant', ts:res.timestamp, text:res.text,
          signals:res.signals||[], auto:mode==='auto'
        });
        if (mode === 'auto') this._notify(res);
      } else {
        this._conversation.push({
          role:'system', ts:this._now(),
          text:'研判失败: '+(res.error||'未知错误'),
          signals:[], auto:false
        });
      }
      this._renderMessages();
    }.bind(this))
    .catch(function() {
      this._loading = false;
      this._conversation.push({role:'system', ts:this._now(), text:'网络错误，请重试', signals:[], auto:false});
      this._renderMessages();
    }.bind(this));
  }

  // === 通知（主动研判时）===
  _notify(res) {
    var summary = (res.text||'').substring(0, 50);
    // Toast
    if (typeof window.showToast === 'function') {
      window.showToast('AI研判: ' + summary + '...');
    }
    // 红点（失焦时累积）
    if (document.activeElement !== this._msgEl) {
      this._badgeCount++;
    }
    this._updateBadge();
  }

  // === UI ===
  _renderMessages() { /* 遍历 _conversation 构建气泡 HTML，插入 _msgEl，滚动到底 */ }
  _updateBadge() {
    var badge = document.getElementById('llmBadge');
    if (!badge) return;
    if (this._badgeCount > 0) {
      badge.textContent = this._badgeCount;
      badge.style.display = '';
    } else {
      badge.style.display = 'none';
    }
  }

  // === 辅助 ===
  _now() {
    var d = new Date();
    return d.getHours()+':'+String(d.getMinutes()).padStart(2,'0')+':'+String(d.getSeconds()).padStart(2,'0');
  }
}
WidgetRegistry.register('LLM_CHAT', LlmChatWidget);
```
