四、一个交易日的完整流程

8:30 盘前准备
gen_baseline APScheduler 自动跑 → dashboard_data.json 刷新
bridge.py 如没启动就 python3 scripts/bridge.py 8088
打开浏览器 http://localhost:8088 → 确认 22 Widget 全部在
你做的事：看一眼仪表盘，确认运行正常。今天笔记空则自动回退昨天数据。
9:25-9:28 竞价结束
sentiment_snapshot 9:25:30 情绪节点快照 → W05
auction_snapshot 9:28 竞价5维快照 → W06 面板更新
你做的事：看 W06 竞价5维（指数竞价/高标/自选池竞价/信号灯）→ 决定今天方向 / W08 三件套信号
9:30-10:00 W1 早盘窗口
PyTDX 5s 个股+指数实时刷新
iwencai 10min 情绪数据自动轮询 → W04 情绪行 + W08 信号灯 + W21 涨停梯队
W08 三件套信号灯自动判定（情绪/涨停收益/标的高开）
W20 AI 盯盘 15min 自动研判 + 浮动聊天框可用
30min 情绪节点快照持续 → W05
你做的事：看 W08 信号 → 决定是否出手 → 操作后在 W15 记流水
10:00-11:30 上午观察
W13 趋势池实时涨幅 + W10 板块净流入
W20 15min 持续研判
W21 涨停梯队（热榜+题材归因+连板性质）
纯看盘，不填表。有疑问点 🤖 问 AI。
11:30-13:00 午休
行情采集暂停
可以回顾 W19 午盘复核（V反+双冰判定）
W05 情绪节点保留午盘快照供参考
13:00-14:30 下午盘
行情恢复，PyTDX 30min 快照持续
W20 每 15min 自动研判（后端 APScheduler 840s，浏览器关了也跑）
看盘、和 AI 对话。输入自然语言问题：持仓分析、板块机会、个股研判
14:00-14:50 W2 尾盘窗口
W09 60min MA10 回踩信号 + 缩量判定
W14 账户风控（熔断/周回撤/月回撤/连亏天数 均从 pnl.db 实时算）
决定是否 W2 低吸/减仓 → W15 记流水（买入/卖出自动扣可用资金）
15:00-15:10 收盘
gen_baseline 15:10 收盘基线刷新（含当日风控指标计算）
sentiment_snapshot 15:00 收盘节点存盘
收盘后笔记自动填完。看一遍，补策略心得和次日预案方向。
收盘后 复盘 + 对抗
稳米：在已自动填好的笔记基础上写次日预案、红方对抗
洋米：执行红方对抗（问财 6 查 + 五维清单 + 三回合）
你需要：看附录A 终稿 → 确认 → 明天直接用
🆕 改 Vault 核心规则后，手动同步到 LLM_RULES.md → AI 下次研判自动跟上

七、AI 研判是怎么工作的

🤖 每次研判（自动/手动）→ 完整流水线

1. 读 LLM_RULES.md+ 2. 读 CLAUDE.md→ 动态拼 system prompt
3. _build_full_snapshot()→ 8域全盘实时数据
4. llm_insights.json→ 最近3轮对话记忆
POST /api/llm→ DeepSeek V4-Flash→ [TEXT] 研判 + [SIGNALS] 信号
_verify_signals()→ 交叉验证 ✅/⚠️
持久化→ llm_insights.json (v2 conversation) pnl.db llm_insights 表
_build_full_snapshot() 读取：指数(实时) + 情绪(wencai 10min) + 连板池(gen+实时) + 趋势池(gen+实时) + 持仓(gen+W15同步) + 板块(gen) + 涨停梯队(hot_list) + 风控(gen)
