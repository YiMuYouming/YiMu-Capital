## 当前健康语义

| 顶栏标签 | 触发条件 | 交易录入 |
|---------|---------|---------|
| 正常 | critical_ok=true, 无 degraded | 允许 |
| 降级 | critical_ok=true, 有 degraded (iwencai/llm/基准缺失) | 允许 |
| 阻断 | trade_entry_allowed=false (行情dead/账户error/锚点缺失) | 关闭 |
| 无响应 | API 不可达 / HTTP 非 2xx | 关闭 |

颜色：正常=绿, 降级=橙, 阻断=红, 无响应=灰。

## 当前已知降级和剩余风险

### 降级（不影响交易录入）

| 降级 | 影响范围 | 触发条件 |
|------|---------|---------|
| iwencai stale | 情绪指标/涨停收益延迟 | iwencai 轮询 > 10min 未更新 |
| llm_config missing | AI 研判不可用 | API token 未配置 |
| baseline delayed | 基线数据过时 | dashboard_data.json > 1h 未更新 |
| account_basis degraded | 今日分项收益不可用 | 持仓缺 `_day_start_price` 或缺 realized_pnl |

### 阻断（关闭交易录入）

| 阻断 | 影响范围 | 触发条件 |
|------|---------|---------|
| account error | 全部 | 锚点被阻断/超卖/ledger_error |
| pnl incomplete | 全部 | valuation_complete=false 持续 |
| quotes dead | 全部 | quotes covered=0 或无报价 |
| account_basis missing_anchor | 全部 | 无当日锚点 |

### 剩余风险

1. **`test_account_ssot.SevenDayClosedPositionsTests.test_correction_reversal_excludes_closed`** 预先存在失败，非 G0-G5 引入。
2. **hernmes PyTDX 不可用**是已知限制，W1/W2 均线/量比技术判断可能不完整。
3. **账户基准缺失**（`day_start_price=null`）会降低今日 PnL 分项可信度，但不影响总资产。
4. **云端部署必须排除 data/**：代码可同步到 hermes，实盘数据只能通过开/收盘脚本或受控 rsync/SQLite backup 流程处理。
5. **`local_dev_proxy.py` 18088 只读代理**在写请求时返回 403 和错误消息，但未在测试中覆盖 full request/response 循环。

## 故障排查顺序

1. 弈沐哥说"看板打不开"或"顶栏无响应"
   ```bash
   lsof -i :8088 | grep ssh          # SSH tunnel 存活？
   curl localhost:8088/api/health     # 服务响应？
   ```

2. 顶栏显示"阻断"或"降级"
   ```bash
   curl localhost:8088/api/pnl/summary | python3 -m json.tool
   curl localhost:8088/api/account/state | python3 -m json.tool
   ```

3. 成交录不进去
   - 确认浏览器用的是 `http://localhost:8088`，不是 `18088`。
   - 检查 `/api/health` 的 `trade_entry_allowed`。
   - 如 18088：错误消息应明确"本地预览只读，请用 8088"。

4. 数据不对（PnL/持仓/行情）
   ```bash
   curl localhost:8088/api/health | python3 -c "import json,sys;d=json.load(sys.stdin);print(d.get('account_basis'))"
   ```
   - 查 `day_start_prices_missing_codes` 和 `closed_missing_realized_codes`。

5. 需要回退代码
   ```bash
   git log --oneline -5
   git diff --stat HEAD~1  # 看最近改动
   ```
   - 代码走 `git pull` 或 `git checkout origin/main -- <file>`，不用 `git reset --hard`。
